# Ultrasonic Distance Sensor controlling OLED

Measure distance with an Ultrasonic Distance Sensor (HC RS04) and show the value on an OLED.

The measured distance can be glitchy and therefore the read value is smoothed out using Exponential Moving Average (EMA)
